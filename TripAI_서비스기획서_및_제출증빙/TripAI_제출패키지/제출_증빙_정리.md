## 4. 축제 기능 확인 결과

- 기획 초안에는 축제 테마가 누락되어 있었으나 현재 코드와 배포 화면에는 포함되어 있습니다.
- 축제 선택 시 축제 후보를 별도로 검색하고 AI 추천 이유에 이름이 언급된 후보만 최대 2개 반영합니다.
- 해당 조건에서 후보가 없으면 일반 관광지로 채우고, 확인된 축제가 없다는 안내를 결과에 포함합니다.
- 공식 행사 일정 API를 사용하지 않으므로 날짜별 개최 여부는 별도 확인이 필요합니다.

## 5. 구현 과정 증빙 요약

개발 과정에서 확인하고 수정한 핵심 내용은 다음과 같습니다.

1. 테마 입력의 `style`/`styles` 이름 불일치로 일부 값이 누락될 수 있는 문제를 통일했습니다.
2. 축제 후보를 무조건 노출하지 않고 AI 추천 이유에 실제로 언급된 축제만 반영하도록 범위를 줄였습니다.
3. 축제가 검색되지 않을 때 사용자가 이상하게 느끼지 않도록 자연스러운 안내를 추가했습니다.
4. 동행 항목을 다시 눌러 선택 해제할 수 있도록 단일 선택 체크박스 방식으로 조정했습니다.
5. 맛집 테마가 일반 장소 검색에도 들어가 음식점이 추천 장소와 중복될 수 있는 한계를 확인했습니다.

> 주의: 본 문서는 배포 사이트 화면과 확인된 코드 동작을 정리한 증빙입니다. 평가 기준에서 AI 코딩 도구의 원본 대화 화면이나 전체 로그를 별도로 요구한다면, 해당 원본 대화 기록은 별도 제출해야 합니다. 존재하지 않는 대화 화면은 증빙으로 만들지 않았습니다.

## 6. 현재 한계와 개선 근거

### 맛집 테마 중복

맛집과 다른 테마를 함께 선택했을 때 `도시명 + 맛집` 검색 결과가 일반 장소 후보에 포함될 가능성이 있습니다. 음식점이 아닌 장소 목록에서는 맛집을 최대한 배제하고, 맛집은 별도 음식점 영역에만 표시하는 것이 적절합니다. 향후 일반 장소 검색에서 `food`를 제외하고 Kakao 카테고리와 장소명·주소 중복 검사를 적용해야 합니다.

### 축제 날짜 검증

현재 결과는 AI와 장소 검색의 조합이므로 공식 개최 일자 확인 기능으로 볼 수 없습니다. 한국관광공사 행사 정보 등 날짜 기반 공식 데이터 연동이 필요합니다.
